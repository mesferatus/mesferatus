## 🦇 Core Skills

</div>

My studies are focused on the connection between **backend development, data analysis, automation and cybersecurity fundamentals**.

I’m currently building a technical foundation that helps me understand how systems are created, how information moves through workflows, how repetitive processes can be improved, and how security analysis helps identify patterns, risks and useful traces inside an environment.

Instead of studying each area separately, I try to connect them in a practical way: backend helps me understand application structure, data helps me transform information into clearer insights, automation helps me reduce manual work, and cybersecurity helps me look at systems with a more analytical and defensive mindset.

| Main focus | How I study and apply it |
